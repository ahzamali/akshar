About Akshar

History

Akshar was conceived and developed in the spring of 1999. It represents a significant student project aimed at solving a real-world problem: the lack of accessible, native Hindi text editing tools for the DOS platform.

Developed at the Computer Sciences Lab, Department of Electronics and Communication, Faculty of Engineering and Technology, Jamia Millia Islamia, New Delhi.

Completion Date: May 16, 1999

The Team

  • Ahzam Ali: Main software architecture, coding, and system integration.
  • Anwar Parvez: Typeface design and font aesthetics.
  • Neeraj Grover: Character display logic and rendering module.

Technical Specifications

  • Programming Language: C
  • Platform: MS-DOS
  • Graphics Engine: Borland Graphics Interface (BGI)
  • Input Method: Custom phonetic mapping via keyboard interrupt handling.
