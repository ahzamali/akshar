User Guide

Running on Modern Systems

Since Akshar is a 16-bit DOS application from 1999, it cannot run directly on modern 64-bit operating systems (Windows 10/11, macOS, Linux). You will need an emulator like DOSBox or DOSBox-X.

Step 1: Install DOSBox

Download and install DOSBox from the official website: dosbox.com.

Step 2: Mount the Application Folder

1. Open DOSBox.

2. Mount the directory where you have downloaded the Akshar files as the C: drive. For example, if you extracted the files to D:\akshar on Windows:

mount c d:\akshar

(Replace d:\akshar with the actual path to your folder)

Step 3: Run Akshar

Switch to the mounted drive and execute the program:

c:
AKSHAR.EXE

Note: Ensure the file EGAVGA.BGI is in the same folder, as it is required for graphics.

Keyboard Mapping

Akshar uses a phonetic keyboard layout to map English keys to Hindi characters. This was designed to be intuitive for users familiar with QWERTY keyboards.

File Operations

Saving Files: When saving a file, you simply need to provide the filename. The editor automatically appends the .HIF (Hindi Font) extension. There is no need to type the extension manually.

Loading Files: Similarly, when opening a file, provide the name of your previously saved work.

Printing

The editor supports direct printing from the DOS interface. Due to the graphical nature of the custom fonts, printing operates in batches. Each page holds approximately 15 lines of text. Long documents will be printed sequentially in these batches.
