It is seen that computers are influencing our society and because of this the english language. We thought of doing something for our mother tongue and planed to design a command interpreter in hindi with capabilities of solving mathematical problems too. We, been working on it for the last few months, have succeeded in designing an editor needed for the interpreter and now working with the interpreter part of it, we call it Akshar.

Akshar is a DOS based Hindi ( Devnagri script ) editor, designed to work on the low end computers. It has been designed using the Turbo C compiler. It uses graphics extensively. At present it has a printer support for Epson 100 dot matrix printer.
